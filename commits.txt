# ── Notes for the next integration ──
#
# Upgrades MUST go through /update-nanoclaw, not `git pull` or `git merge`.
# v2.1.x added a startup tripwire: the host records the version it reached via a
# supported path in data/upgrade-state.json and refuses to start when that record
# does not match the running code. A raw merge trips it — see
# docs/upgrade-recovery.md. Clearing the marker by hand skips the container
# rebuild, which is what the tripwire is actually protecting.
